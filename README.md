# Chest Looting Game

This is a chest looting game in which the player rolls a die and selects a chest, leading to different outcomes.

This was a small learning project intended to practice some Rust after reading chapters 1 through 6 of the [The Rust Programming Language](https://doc.rust-lang.org/stable/book/title-page.html) book.

## Download

### Windows

1. Download the latest `chest_looting_game.exe` alpha from the [Releases Page](https://github.com/monolithicTeto/chest_looting_game/releases).
2. Double-click to run. Windows may show a SmartScreen warning since the file isn't code-signed — click **More info**, then **Run anyway**.

### Linux

1. Download the latest `chest_looting_game` alpha from the [Releases Page](https://github.com/monolithicTeto/chest_looting_game/releases).
2. Run with:
```
chmod +x chest_looting_game
./chest_looting_game
```

Have fun!
